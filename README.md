#  QueHayMed

QueHayMed es una plataforma web que centraliza todos los eventos con boletería disponibles en Medellín y áreas aledañas. Desde conciertos hasta eventos deportivos, encuentra toda la oferta cultural de la ciudad en un solo lugar.

##  Descripción

Aplicación web diseñada para facilitar la búsqueda y adquisición de entradas a eventos en Medellín. Los usuarios pueden visualizar eventos destacados, ver detalles y próximamente comprar entradas con generación de tickets digitales con código QR.

### Características principales:
-  Dashboard de eventos
-  Sistema de verificación de edad para contenido restringido
-  Diseño responsive (Mobile First)
-  Interfaz moderna y amigable

##  Tecnologías utilizadas

- HTML5
- CSS3 (Variables CSS, Flexbox)
- JavaScript (Vanilla)
- Diseño Mobile First
